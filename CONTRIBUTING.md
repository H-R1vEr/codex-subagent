# Contributing

Open a focused issue or pull request with the task trigger, supplied input assumptions, proposed behavior and at least one failure/acceptance scenario. Do not add generic prose that duplicates agent capabilities. Keep entrypoints concise; put conditional detail in linked references.

Use lowercase hyphenated folder/frontmatter names, maintain `catalog.json`, and supply `agents/openai.yaml`. New scientific equations or claims need exact sources and a benchmark plan. Never commit private research data, credentials, copyright-restricted figures or third-party skill bodies without reviewed permission and notices.

Before a PR run the commands in [validation](docs/validation.md), build the site and check changed pages visually. Report actual checks and untested behavior separately. Installer changes need collision, dry-run and traversal tests. Journal integrations must state upstream/ref/license without implying publisher endorsement.

Contributions are licensed under MIT; by submitting you confirm that you have the right to contribute them under that license. Maintainers review scientific assumptions and evidence separately from style. No guaranteed acceptance or publication decisions are made by this repository.
