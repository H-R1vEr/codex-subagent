# 地震快速研判 / earthquake-rapid-analysis

## Input contract

Use the user's actual artifacts, purpose and permitted output location. Identify missing inputs that affect the result; label assumptions. Instructions are a workflow, not an embedded numerical engine. Install or use scientific software only when needed and available. Preserve originals and distinguish observed, simulated and historical evidence.

## Workflow

1. Record the analysis cutoff with timezone. Collect agency event IDs, URLs, retrieval times, origin time, magnitude type, location/depth, revision and uncertainty from authoritative available sources.
2. Reconcile revisions without mixing different event solutions or magnitude scales. Preserve conflicting values in a source table and state which solution drives calculations.
3. Separate instrument observations, modeled shaking and unverified reports. When waveform data are absent, label modeled estimates; do not imply recorded PGA or structural damage.
4. If a provisional scenario is appropriate, state model/domain/site assumptions and uncertainty. For exposure use timestamped sourced datasets and distinguish exposure from damage or loss.
5. Produce a concise assessment with known facts, unresolved items and practical follow-up data needs. Do not invent casualty figures, imminent-aftershock claims or official instructions.
6. Update only when requested or through an authorized monitoring workflow; preserve prior snapshots and show changes.

## Deliverable

Timestamped source/revision table; facts versus modeled estimates; uncertainty notes; preliminary map if supported; next data needs and limitations.

Include source locators and environment/method details needed to check the result. State the weakest evidence and the largest remaining gap; use “none identified” when applicable.

## Acceptance scenario

Two agencies report Mw 6.2 and ML 6.7: retain both scales and sources instead of selecting the larger number as a confirmed Mw.
