# 论文主线 / paper-storyline

## Input contract

Use the user's actual artifacts, purpose and permitted output location. Identify missing inputs that affect the result; label assumptions. Instructions are a workflow, not an embedded numerical engine. Install or use scientific software only when needed and available. Preserve originals and distinguish observed, simulated and historical evidence.

## Workflow

1. Identify the question, prior limitation, actual advance and audience. Read available results before drafting a novelty claim; absent literature verification leaves novelty provisional.
2. Build an argument map: question → method → finding → evidence → implication, with limitations at the relevant links. Separate tested findings from proposed mechanisms.
3. Arrange figures by logical dependence and specify the claim each panel earns. Do not add experiments, significance or validation that did not occur.
4. Choose the narrowest strong central claim and place negative/inconclusive evidence where it constrains the story. Preserve source facts when restructuring.
5. Produce an outline or requested text and a gap list. If journal constraints are requested, consult the optional bridge; lack of a journal package does not block an evidence-based outline.

## Deliverable

Central claim; section/figure argument map; evidence-linked outline or draft; novelty verification status and unresolved gaps.

Include source locators and environment/method details needed to check the result. State the weakest evidence and the largest remaining gap; use “none identified” when applicable.

## Acceptance scenario

Results show an improved regional fit but not worldwide transfer: build a regional paper rather than inventing a universal model claim.
