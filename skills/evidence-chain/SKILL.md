# 证据链 / evidence-chain

## Input contract

Use the user's actual artifacts, purpose and permitted output location. Identify missing inputs that affect the result; label assumptions. Instructions are a workflow, not an embedded numerical engine. Install or use scientific software only when needed and available. Preserve originals and distinguish observed, simulated and historical evidence.

## Workflow

1. Extract central and supporting claims with scope (population, region, time, mechanism). Link each to an actual figure/table, dataset and analysis or citation using stable IDs and locators.
2. Distinguish direct evidence, inference, background citation and speculation. A cited review is not necessarily primary support for the exact claim.
3. Audit alternative explanations, selection bias, dependent observations and missing negative controls. Do not upgrade association to causality from writing alone.
4. Mark each link supported, partial, contradicted or unverified with a reason. Missing artifacts stay unverified; do not create provenance or fill gaps with historical results.
5. Suggest a proportionate next analysis or narrower wording for each material gap. Respect requests for audit-only work.

## Deliverable

Claim-to-evidence matrix; source locators; conflicts and missing links; prioritized repairs and scoped claim wording.

Include source locators and environment/method details needed to check the result. State the weakest evidence and the largest remaining gap; use “none identified” when applicable.

## Acceptance scenario

A conclusion claims generality across Italy but the sample is one sequence: narrow the claim or identify independent regional evidence.
