# Security and sensitive information

Never submit credentials, private patient/person information or unpublished datasets in an issue. Skills can read task artifacts through host tools; review external packages before installing. The local installer copies original skills and never downloads or executes upstream content.

For vulnerabilities use GitHub private vulnerability reporting if enabled, or a published maintainer private contact. Before launch enable that route. This V1 does not invent contact details or promise response times. For non-sensitive bugs, provide a minimal synthetic reproduction and affected version.
